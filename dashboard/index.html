    Safety Checks (Enable / Disable & Tune)

    Changes apply to the robot immediately and are remembered across reloads. They are re-sent automatically on the next connect.

    ▸ Stall Detection
    Triggers when: |PWM| ≥ PWM% AND |velocity| < RPM AND (position error > Error° in POSITION/GHOST mode), sustained for Time.
    Cause: motor blocked by obstacle, mechanical jam, or wiring fault.
    ▸ Encoder Check
    Triggers when (either):
    • Phase inversion: PWM > 50% one way, RPM > 5 RPM the other way
    • Signal loss: PWM > 50%, RPM near 0, encoder counts frozen for 1 second
    Cause: encoder cable disconnected, A/B swapped, or hardware fault.
    ▸ Over-Rotation
    Triggers when: absolute position exceeds ±Limit from home. Acts as a virtual hard-stop (clamps target). Escalates to E-Stop after 1 s sustained breach.
    Cause: wire-twist protection — prevents internal wiring from snapping.
    Note: disabling this removes both the fault, the virtual hard-stop, and the 1 s E-Stop escalation.
    ▸ Joystick Check
    Triggers when:
    • ESP32 sends a disconnect status packet, OR
    • No valid packet received for 1000 ms (link silence watchdog)
    Cause: joystick power off, Bluetooth/wireless link lost, or ESP32 fault.
    ▸ Physical E-Stop Button
    Triggers when: PA5 E-Stop input is held LOW for the debounce window (80 ms idle, 500 ms while motor running, 1500 ms during homing/diagnostic).
    Cause: physical red E-Stop button pressed on the control panel.
    Warning: disabling this makes the hardware E-Stop button non-functional in software. Only disable for bench testing without the button wired.
    ⚡ Overcurrent Protection HARDWARE
    Always active. Motor relay opens if |current| exceeds the limit for the debounce time. Sets FAULT_OVERCURRENT.
    Cause: motor jammed under load, short circuit, or H-bridge fault.
    Note: cannot be disabled in software — requires a firmware recompile to change limits.
