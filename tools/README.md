# tools/

Python utilities for development and debugging.

| File | ใช้ทำอะไร | Run |
|------|-----------|-----|
| `telemetry_viewer.py` | แสดง telemetry จาก STM32 แบบ real-time (terminal) | `python telemetry_viewer.py` |
| `modbus_diagnostics.py` | ตรวจสอบ Modbus register และ heartbeat | `python modbus_diagnostics.py` |

ต้องการ: `pip install pyserial`
